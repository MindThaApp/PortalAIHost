## 應用程式名稱

Portal AI Host

(應用程式名稱維持英文。若名稱已被使用，備選名稱: "Portal AI Host for Windows", "Portal Local AI Host")

## 簡短說明 (商店「簡短說明」，最多 1,000 個字元)

在您自己的電腦上執行本機 AI 模型，並與您的 Portal 應用程式共用。按一下即可依您的硬體挑選最適合的模型，下載並保持隨時可用。您的文字只留在這台電腦上：不需要帳號、不需要雲端、不需要訂閱。

## 說明

Portal AI Host 為您的電腦提供專屬的 AI 模型，並讓您的其他應用程式使用它。

與其讓每個應用程式各自下載模型，或把您的文字傳送到雲端服務，Portal AI Host 只在電腦上保留一個模型，並與您允許的應用程式共用。Voice Portal 和其他 Portal 應用程式因此能用更大、更好的模型來撰寫摘要、會議紀錄和回答，不必各自攜帶模型。

輕鬆設定
- 首次執行時，程式會檢查您的電腦 (記憶體、顯示卡、可用磁碟空間)，並推薦在此電腦上運作良好的最佳模型，附上淺顯的說明。
- 按一下即可下載。下載可以暫停與繼續，每個檔案在使用前都會經過驗證。
- 不需要另外安裝：引擎已內建。不需要 Python、不需要命令列、不需要其他工具。

以隱私為設計核心
- 模型在這台電腦上執行。提示與回答不會離開這台電腦。
- 不需要帳號，也不需要登入。
- 沒有分析資料。選擇性的當機報告不會包含您的檔案或您輸入的內容，並且可以關閉。您的提示永遠不會被儲存或記錄。
- 主機只監聽本機 (回送位址)。網路上的其他電腦無法連線。

由您掌控
- 應用程式必須先詢問，才能使用主機，由您決定：允許、拒絕或稍後決定。您隨時可以移除某個應用程式的存取權。
- 主機會顯示要求的應用程式是否已驗證 (發行者)，讓您知道是誰在提出要求。
- 您可以選擇模型的儲存位置，並移除不再需要的模型。主機只會刪除它自己下載的檔案。
- 「隨 Windows 啟動」為選用功能，預設關閉，需由您開啟。

適用您的硬體
- 透過 Vulkan 使用您的顯示卡 (支援 AMD、NVIDIA 和 Intel)，沒有合適的 GPU 時會自動改用處理器。
- 模型閒置時釋放記憶體，或依您的偏好保持載入。

給開發人員
- 主機在 127.0.0.1 上提供標準的 OpenAI 相容 API (支援串流的聊天補全、嵌入和模型清單)，現有的用戶端程式庫可直接使用。每個應用程式都需要先取得使用者同意。

模型從發行者在 Hugging Face 上的頁面下載。每個模型都有自己的授權條款；本應用程式只提供授權允許商業使用的模型 (Apache 2.0 或 MIT)。

## 功能 (Partner Center「產品功能」，最多 20 項，每項 200 個字元)

1. 在您的電腦上於本機執行 AI 模型，不需要雲端
2. 所有 Portal 應用程式共用同一個模型
3. 為您的硬體推薦最佳模型
4. 按一下即可下載，支援暫停、繼續與檔案驗證
5. 使用顯示卡 (Vulkan)，並自動改用 CPU
6. 不需要帳號、不需要登入、不需要訂閱
7. 沒有分析資料；當機報告為選用且已去識別化；提示永遠不會被儲存或記錄
8. 只監聽本機 (回送位址)
9. 應用程式必須先詢問；您可以允許、拒絕或移除存取權
10. 顯示提出要求的應用程式是否已驗證
11. 閒置時釋放記憶體，或保持模型載入
12. 可選擇模型的儲存資料夾
13. 可選擇隨 Windows 啟動，並顯示工作列圖示
14. 「試用」方塊，用來確認模型可以正常運作
15. 供開發人員使用的 OpenAI 相容本機 API
16. 多個應用程式同時要求時公平分配
17. 引擎停止時會自動復原

## 系統需求 (Partner Center「系統需求」與商店文字)

最低需求 (在 Partner Center > 屬性 > 系統需求 中設定):
- Windows 11 (版本 21H2、組建 22000) 或更新版本，x64 或 Arm64。
- 記憶體: 8 GB。
- 可用磁碟空間: 5 GB (應用程式本身很小；模型為 2 至 20 GB，較大的選用模型最多約 140 GB)。

建議配置:
- 記憶體: 16 GB 以上 (大型模型建議 32 GB 以上)。
- 顯示卡: 支援 Vulkan、視訊記憶體 8 GB 以上 (AMD、NVIDIA 或 Intel)。
- 可用磁碟空間: 25 GB。

商店文字 (「其他系統需求」/ 說明頁尾):
> 記憶體 16 GB、視訊記憶體 8 GB 的顯示卡可獲得最佳效能。沒有合適的顯示卡時，模型會在處理器上執行，速度較慢。Arm64 電腦會在處理器上執行模型。模型需要 2 至 20 GB 的可用磁碟空間。
