## คำอธิบายสั้น

รันโมเดล AI ในเครื่องบนพีซีของคุณเองและแชร์ให้แอป Portal ของคุณใช้ได้ คลิกเดียวแอปจะเลือกโมเดลที่เหมาะกับฮาร์ดแวร์ของคุณ ดาวน์โหลด และเตรียมให้พร้อมใช้ ข้อความของคุณอยู่ในเครื่องนี้เท่านั้น: ไม่ต้องมีบัญชี ไม่ใช้คลาวด์ ไม่มีค่าสมาชิก

## คำอธิบาย

Portal AI Host มอบโมเดล AI ให้พีซีของคุณ และให้แอป Portal อื่นๆ ใช้งานร่วมกันได้

แทนที่จะให้แอปทุกตัวดาวน์โหลดโมเดลของตัวเอง หรือส่งข้อความของคุณไปยังบริการคลาวด์ Portal AI Host เก็บโมเดลเพียงชุดเดียวไว้ในพีซีของคุณ และแชร์ให้แอปที่คุณอนุญาตเท่านั้น ทำให้ Voice Portal และแอป Portal อื่นๆ สามารถเขียนสรุป บันทึกการประชุม และคำตอบด้วยโมเดลที่ใหญ่และฉลาดกว่าที่แต่ละแอปจะรับไหวได้เอง

ตั้งค่าง่าย
- ในการเปิดครั้งแรก แอปจะตรวจสอบพีซีของคุณ (หน่วยความจำ การ์ดจอ พื้นที่ว่างในดิสก์) และแนะนำโมเดลที่ทำงานได้ดีที่สุดบนเครื่องของคุณ พร้อมคำอธิบายที่เข้าใจง่าย
- คลิกเดียวเพื่อดาวน์โหลด สามารถหยุดชั่วคราวและดาวน์โหลดต่อได้ และทุกไฟล์จะถูกตรวจสอบก่อนใช้งาน
- ไม่ต้องติดตั้งอะไรเพิ่ม เอนจินมีมาให้ในตัวแล้ว ไม่ต้องมี Python ไม่ต้องใช้คำสั่งบรรทัดคำสั่ง และไม่ต้องมีเครื่องมือเพิ่มเติม

ออกแบบเพื่อความเป็นส่วนตัว
- โมเดลทำงานบนพีซีเครื่องนี้ คำถามและคำตอบไม่ออกจากเครื่อง
- ไม่มีบัญชีและไม่ต้องลงชื่อเข้าใช้
- ไม่มีการวิเคราะห์การใช้งาน รายงานข้อขัดข้องที่เป็นตัวเลือกจะไม่มีไฟล์หรือข้อความที่คุณพิมพ์ และคุณปิดได้ คำถามของคุณจะไม่ถูกบันทึกหรือเก็บลงล็อก
- โฮสต์รับการเชื่อมต่อเฉพาะบนเครื่องนี้ (loopback) คอมพิวเตอร์อื่นในเครือข่ายของคุณเข้าถึงไม่ได้

คุณเป็นผู้ควบคุม
- แอปใดๆ ต้องขออนุญาตก่อนใช้โฮสต์ และคุณตัดสินใจได้: อนุญาต ปฏิเสธ หรือตัดสินใจภายหลัง คุณเพิกถอนสิทธิ์ของแอปได้ทุกเมื่อ
- โฮสต์จะแสดงว่าแอปที่ขอสิทธิ์ได้รับการยืนยัน (ผู้เผยแพร่) หรือไม่ เพื่อให้คุณรู้ว่าใครเป็นผู้ขอ
- เลือกที่เก็บโมเดลได้ และลบโมเดลที่ไม่ต้องการแล้วได้ โฮสต์จะลบเฉพาะไฟล์ที่ดาวน์โหลดด้วยตัวมันเองเท่านั้น
- การเริ่มทำงานพร้อม Windows เป็นตัวเลือก และปิดอยู่จนกว่าคุณจะเปิดเอง

ทำงานกับฮาร์ดแวร์ของคุณ
- ใช้การ์ดจอผ่าน Vulkan (AMD, NVIDIA และ Intel) และสลับไปใช้ซีพียูเมื่อไม่มี GPU ที่เหมาะสม
- คืนหน่วยความจำเมื่อโมเดลไม่ได้ใช้งาน หรือเก็บโมเดลไว้ในหน่วยความจำหากคุณต้องการ

สำหรับนักพัฒนา
- โฮสต์ให้ API ที่เข้ากันได้กับ OpenAI มาตรฐานบน 127.0.0.1 (chat completions แบบสตรีมมิง embeddings และรายการโมเดล) ไลบรารีไคลเอนต์ที่มีอยู่จึงใช้งานได้ทันที แอปทุกตัวต้องได้รับความยินยอมจากผู้ใช้ก่อน

โมเดลดาวน์โหลดจากหน้าของผู้เผยแพร่บน Hugging Face แต่ละโมเดลมีลิขสิทธิ์การใช้งานของตัวเอง แอปจะแสดงเฉพาะโมเดลที่อนุญาตให้ใช้เชิงพาณิชย์ได้ (Apache 2.0 หรือ MIT)

## ฟีเจอร์ (สูงสุด 20 รายการ รายการละไม่เกิน 200 อักขระ)

1. รันโมเดล AI ในเครื่องบนพีซีของคุณ ไม่ต้องใช้คลาวด์
2. โมเดลเดียวที่แอป Portal ทั้งหมดของคุณใช้ร่วมกัน
3. แนะนำโมเดลที่ดีที่สุดสำหรับฮาร์ดแวร์ของคุณ
4. ดาวน์โหลดคลิกเดียว พร้อมหยุดชั่วคราว ดาวน์โหลดต่อ และตรวจสอบไฟล์
5. ใช้การ์ดจอ (Vulkan) พร้อมสลับไปใช้ซีพียูโดยอัตโนมัติ
6. ไม่มีบัญชี ไม่ต้องลงชื่อเข้าใช้ ไม่มีค่าสมาชิก
7. ไม่มีการวิเคราะห์การใช้งาน รายงานข้อขัดข้องเป็นตัวเลือกและถูกล้างข้อมูลแล้ว คำถามไม่ถูกบันทึกหรือเก็บลงล็อก
8. รับการเชื่อมต่อเฉพาะบนพีซีนี้ (loopback)
9. แอปต้องขอก่อน คุณอนุญาต ปฏิเสธ หรือเพิกถอนได้
10. แสดงว่าแอปที่ขอสิทธิ์ได้รับการยืนยันหรือไม่
11. คืนหน่วยความจำเมื่อไม่ใช้งาน หรือคงโมเดลไว้ในหน่วยความจำ
12. เลือกโฟลเดอร์สำหรับเก็บโมเดลได้
13. เปิดพร้อม Windows ได้ตามต้องการ พร้อมไอคอนในถาดระบบ
14. กล่อง "ลองใช้" เพื่อตรวจสอบว่าโมเดลทำงานได้
15. API ภายในเครื่องที่เข้ากันได้กับ OpenAI สำหรับนักพัฒนา
16. แบ่งการใช้งานอย่างเป็นธรรมเมื่อหลายแอปขอพร้อมกัน
17. กู้คืนตัวเองอัตโนมัติหากเอนจินหยุดทำงาน

## ความต้องการของระบบ (ข้อความในรายการ)

> ทำงานได้ดีที่สุดเมื่อมีหน่วยความจำ 16 GB และการ์ดจอที่มีหน่วยความจำวิดีโอ 8 GB หากไม่มีการ์ดจอที่เหมาะสม โมเดลจะทำงานบนซีพียู ซึ่งช้ากว่า พีซี Arm64 รันโมเดลบนซีพียู โมเดลต้องใช้พื้นที่ว่างในดิสก์ 2 ถึง 20 GB

ขั้นต่ำ: Windows 11 (รุ่น 21H2 บิลด์ 22000) ขึ้นไป สถาปัตยกรรม x64 หรือ Arm64 หน่วยความจำ 8 GB พื้นที่ว่างในดิสก์ 5 GB
แนะนำ: หน่วยความจำ 16 GB ขึ้นไป (32 GB ขึ้นไปสำหรับโมเดลขนาดใหญ่) การ์ดจอที่รองรับ Vulkan และมีหน่วยความจำวิดีโอ 8 GB ขึ้นไป (AMD, NVIDIA หรือ Intel) พื้นที่ว่างในดิสก์ 25 GB
