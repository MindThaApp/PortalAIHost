내 PC에서 로컬 AI 모델을 실행하고 Portal 앱과 함께 사용하세요. 한 번의 클릭으로 하드웨어에 맞는 모델을 고르고, 내려받아 바로 쓸 수 있게 준비합니다. 입력한 텍스트는 이 PC 안에만 머뭅니다. 계정, 클라우드, 구독이 필요 없습니다.

## 설명

Portal AI Host는 내 PC에 전용 AI 모델을 두고, 다른 Portal 앱이 그 모델을 사용할 수 있게 해 줍니다.

앱마다 모델을 따로 내려받거나 텍스트를 클라우드 서비스로 보내는 대신, Portal AI Host는 모델 하나를 PC에 두고 허용한 앱과 함께 씁니다. Voice Portal 등 Portal 앱은 혼자서는 담을 수 없는 더 크고 성능 좋은 모델로 요약, 회의록, 답변을 작성할 수 있습니다.

간편한 설정
- 처음 실행하면 PC(메모리, 그래픽 카드, 여유 디스크 공간)를 확인하고, 이 PC에서 잘 돌아가는 최적의 모델을 쉬운 설명과 함께 추천합니다.
- 클릭 한 번으로 내려받을 수 있습니다. 다운로드는 일시 중지하고 이어서 받을 수 있으며, 모든 파일은 사용 전에 검사됩니다.
- 따로 설치할 것이 없습니다. 엔진이 앱에 내장되어 있습니다. Python도, 명령줄도, 추가 도구도 필요 없습니다.

개인정보를 지키는 설계
- 모델은 이 PC에서 실행됩니다. 입력한 내용과 답변은 PC 밖으로 나가지 않습니다.
- 계정 생성이나 로그인이 필요 없습니다.
- 분석 데이터를 수집하지 않습니다. 선택 사항인 충돌 보고서에는 내 파일이나 입력한 내용이 포함되지 않으며, 끌 수 있습니다. 입력한 프롬프트는 저장되거나 기록되지 않습니다.
- 호스트는 이 PC(루프백)에서만 연결을 받습니다. 같은 네트워크의 다른 컴퓨터는 접근할 수 없습니다.

내가 직접 관리합니다
- 앱이 호스트를 사용하려면 먼저 요청해야 하며, 허용, 거부, 나중에 결정 중에서 내가 선택합니다. 앱의 접근 권한은 언제든지 취소할 수 있습니다.
- 요청한 앱이 검증된 발행자인지 여부를 호스트가 표시하므로 누가 요청하는지 알 수 있습니다.
- 모델을 저장할 위치를 고를 수 있고, 더 이상 필요 없는 모델은 삭제할 수 있습니다. 호스트는 자신이 내려받은 파일만 삭제합니다.
- Windows 시작 시 자동 실행은 선택 사항이며, 직접 켜기 전까지 꺼져 있습니다.

내 하드웨어에 맞춰 동작
- Vulkan으로 그래픽 카드(AMD, NVIDIA, Intel)를 사용하며, 적합한 GPU가 없으면 프로세서로 자동 전환합니다.
- 모델이 사용되지 않을 때 메모리를 비우거나, 원하면 모델을 계속 로드해 둘 수 있습니다.

개발자용
- 호스트는 127.0.0.1에서 표준 OpenAI 호환 API(스트리밍 채팅 완성, 임베딩, 모델 목록)를 제공하므로 기존 클라이언트 라이브러리를 그대로 쓸 수 있습니다. 모든 앱은 먼저 사용자의 승인이 필요합니다.

모델은 발행자의 Hugging Face 페이지에서 내려받습니다. 각 모델에는 고유한 라이선스가 있으며, 이 앱은 상업적 사용이 허용된 모델(Apache 2.0 또는 MIT)만 제공합니다.

## 기능 (Partner Center "제품 기능", 최대 20개, 항목당 200자)

1. PC에서 AI 모델을 로컬로 실행, 클라우드 불필요
2. 모든 Portal 앱이 하나의 모델을 공유
3. 내 하드웨어에 가장 적합한 모델을 추천
4. 일시 중지, 이어 받기, 파일 검사를 갖춘 원클릭 다운로드
5. Vulkan으로 그래픽 카드 사용, 자동으로 CPU 대체
6. 계정, 로그인, 구독 불필요
7. 분석 없음, 충돌 보고서는 선택 사항이며 개인정보 제거, 프롬프트는 저장·기록되지 않음
8. 이 PC(루프백)에서만 연결 수락
9. 앱은 먼저 요청해야 함. 허용, 거부, 접근 권한 제거 가능
10. 요청하는 앱이 검증되었는지 표시
11. 유휴 시 메모리 해제, 또는 모델 계속 로드
12. 모델 저장 폴더 선택 가능
13. 선택 사항인 Windows 시작 시 자동 실행(트레이 아이콘 포함)
14. 모델 동작을 확인하는 "체험" 입력창
15. 개발자를 위한 OpenAI 호환 로컬 API
16. 여러 앱이 동시에 요청할 때 공정한 처리
17. 엔진이 멈추면 스스로 복구

## 시스템 요구 사항 (Partner Center "시스템 요구 사항" 및 스토어 문구)

최소 사양 (Partner Center > 속성 > 시스템 요구 사항에서 설정):
- Windows 11(버전 21H2, 빌드 22000) 이상, x64 또는 Arm64.
- 메모리: 8GB.
- 여유 디스크 공간: 5GB (앱 자체는 작으며, 모델은 2~20GB, 더 큰 선택 모델은 약 140GB까지입니다).

권장 사양:
- 메모리: 16GB 이상 (대형 모델은 32GB 이상).
- 그래픽: 비디오 메모리 8GB 이상의 Vulkan 지원 GPU (AMD, NVIDIA 또는 Intel).
- 여유 디스크 공간: 25GB.

스토어 문구 ("추가 시스템 요구 사항" / 설명 하단):
> 메모리 16GB, 비디오 메모리 8GB의 그래픽 카드에서 가장 잘 동작합니다. 적합한 그래픽 카드가 없으면 모델은 프로세서에서 실행되며 속도가 느립니다. Arm64 PC는 프로세서에서 모델을 실행합니다. 모델에는 2~20GB의 여유 디스크 공간이 필요합니다.
